# 7. Appendix

## Purpose
This section provides quick-reference notes, definitions, and common problem recovery steps.

## Quick Glossary

### Active
A record that can still be used in normal work.

### Branch Scope
The branch type where a recipe is allowed to be used.

### Closing Stock
What remains at the end of the session.

### Credit Customer
A customer allowed to buy now and pay later.

### Finished Product
The final item produced by a recipe and sold to customers.

### Opening Stock
What is available at the start of the session.

### Production Item
A product created from a recipe and then sold.

### Sale Mode
How a product is sold:
- weight
- portion
- cup
- piece

### Session
The working stock record for a branch for a specific day.

### Wholesale Customer
A customer whose sale should use wholesale pricing.

## Fast Answers To Common Questions

### Why Is A Product Missing In Recipe Final Product?
The product must be created first and set up as a production item.

### Why Is A Product Prompt Different During Sale?
The product’s sale mode or custom sales prompt controls what the cashier sees.

### Why Can’t I Sell Right Now?
There may be no open stock session for the branch.

### Why Can’t I Close The Session?
Closing stock may be missing or required sales/payment conditions may not be complete.

### Why Can’t I Print A Receipt?
Receipts are for paid sales. Record payment first.

## Admin Quick Setup Checklist
Use this when starting a new branch or onboarding a new site:

1. Create branches
2. Create users
3. Assign cashier users to branches
4. Create products
5. Create production items
6. Create recipes
7. Create suppliers
8. Create customers
9. Create partners
10. Test one stock session and one sale

## Cashier Quick Start Checklist
Use this at the start of each day:

1. Log in
2. Confirm branch
3. Open stock session
4. Record opening stock
5. Confirm products needed for the day exist
6. Begin operations

## End-Of-Day Checklist
Use this before logging out:

1. Sales are entered
2. Payments are recorded
3. Wastage is recorded
4. Stock share is recorded if used
5. Closing stock is recorded
6. Session is closed

## When To Ask For Admin Help
Escalate when:
- the branch is wrong
- a user has no correct access
- a required product is missing
- a recipe needs to be corrected
- a branch record needs editing
- reports need review
- the wrong person was created or assigned

## Good Data Habits
- use clear names for branches, products, recipes, customers, and partners
- do not create duplicate records unless required
- check prices before saving products
- check customer type before creating a sale
- count stock before entering closing values
- use notes only when they add value

### For New Cashiers

## Final Reminder
The system works best when records are created in order.

If something looks missing later, check whether the earlier setup step was skipped:
- branch
- user
- product
- recipe
- session
- sale
- payment
