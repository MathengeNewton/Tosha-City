# ToshaCity Butchery User Manual

## Purpose
This manual teaches a new admin or cashier how to use the application step by step.

Use it as:
- a training manual for new staff
- a setup checklist for a new branch or new site
- a daily operations guide
- a printable handbook that can be compiled into one PDF

## Intended Audience
- Admin users
- Cashier users
- Supervisors training new users

## How To Compile Into One PDF
Preferred option:

1. Convert `complete-manual.md` directly into PDF

Alternative option:
Merge the section files below in order, then convert the merged file into PDF.

## Section Merge Order
Combine the files in this order:

1. `index.md`
2. `user-manual.md`
3. `role-guide.md`
4. `admin-setup-guide.md`
5. `cashier-operations-guide.md`
6. `sop-process-flows.md`
7. `reports-guide.md`
8. `appendix.md`

If you use a Markdown-to-PDF tool, keep the files in this order so the table of contents reads naturally.

## Reading Order
If you are new to the system, read the manual in this order:

1. Read the introduction first
2. Read the role guide for your role
3. If you are an admin, complete the setup guide
4. If you are a cashier, read the daily operations guide
5. Use the SOP section during live work
6. Use the reports guide when reviewing branch performance
7. Use the appendix when you need quick definitions or recovery notes

## What This Manual Covers
- Logging in and understanding the dashboard
- Understanding branch-based work
- Creating branches, users, products, recipes, suppliers, customers, and partners
- Opening and managing stock sessions
- Recording production runs
- Creating sales and recording payments
- **Who may correct data:** admins edit/delete saved sales and stock entries; cashiers add new operational records only
- Closing daily work correctly
- Reading reports

## What This Manual Does Not Cover
- Internal code structure
- Developer workflows
- Technical implementation details

## Success Standard
After reading this manual, a new person should be able to:
- understand what the system is for
- know what their role allows them to do
- set up the system in the right order
- complete daily branch work without missing required steps
- read the main operational reports with confidence
