# 4. Cashier Operations Guide

## Purpose
This section teaches a cashier how to run daily branch work from opening to close.

## Intended Audience
- Cashier users

## Daily Work Sequence
Use this order every day:

1. Log in
2. Confirm branch
3. Open stock session
4. Record opening stock
5. Record incoming stock if needed
6. Record production runs if prepared items are made
7. Create sales
8. Record payment for unpaid sales
9. Record wastage or stock share if needed
10. Record closing stock
11. Close stock session

## Step 1: Log In

### Open
Open the login page.

### Enter
- username or email
- password

### After Login
You should land on the dashboard.

## Step 2: Confirm Your Branch

### Where To Look
Check the branch shown in the header area.

### Why It Matters
Your stock session, production, and sales should happen inside the correct branch.

### If The Branch Is Wrong
Stop and ask the admin to fix your branch assignment before you continue.

## Step 3: Open Stock Session

### Open This Page
Open `Stock Session`.

### If No Session Is Open
Use the `Open Stock Session` or `Open Session` action.

### Expected Result
The current session should show as open for your branch.

### Important Rule
Do not start selling before an open session exists.

## Step 4: Record Opening Stock

### Stay On
The `Stock Session` page.

### Open The Current Session
If needed, open the session details view.

### Use The Opening Stock Area
Record the products available at the start of the day.

### What To Enter
- product
- quantity
- unit
- notes if needed

### Save
Save each entry after confirming the quantity.

### Expected Result
The opening stock entries should appear in the session records.

## Step 5: Record Incoming Stock

### When To Use
Use this only when new stock arrives during the day.

### Open
The incoming stock area inside the open session.

### Enter
- product
- quantity
- unit
- supplier
- notes if needed

### Save
Save the entry.

### Expected Result
The incoming stock appears in the session and contributes to stock movement.

## Step 6: Record Production Runs

### When To Use
Use this when the branch produces prepared items such as:
- mutura
- soup
- pork fry

### Open
The `Production` tab inside the stock session.

### Click
`Record production run`

### Fill In
- `Recipe`
- `Actual output`
- `Wastage` if any
- actual ingredient quantities used
- `Notes` if needed

### Save
Click `Save production run`.

### Expected Result
The production run should appear in the production runs list for the session.

## Step 7: Create A Sale

### Open This Page
Open `New Sale`.

### Confirm
- an open stock session exists
- the branch shown on the page is correct

### Set Sale Header First
Before adding items:
- choose `Payment Method`
- choose `Customer` if needed

### When To Select A Customer
- select a customer for credit sales
- select a wholesale customer if the sale should use wholesale pricing

### Add Sale Items
Click `Add Item`.

### For Each Item
1. select the product
2. confirm the prompt shown for that product
3. enter quantity or amount depending on the item type
4. confirm price

### Important Prompt Behavior
Some items are not sold by weight.

Examples:
- soup may ask for number of cups
- mutura may ask for number of portions
- some items may ask for number of pieces

### Save The Sale
Submit the sale after all items are correct.

### Expected Result
The system should create the sale and open the sale details page.

## Step 8: Record Payment

### Open
The sale details page for the sale.

### If The Sale Is Unpaid
Click `Record Payment`.

### Fill In
- payment method
- MPESA reference if payment is MPESA

### Save
Submit the payment.

### Expected Result
The sale should change to paid status.

### After Payment
You can print the receipt for a paid sale.

## Step 9: Record Wastage

### When To Use
Use this when stock is damaged, lost, spoiled, or otherwise not sellable.

### Open
The wastage area inside the stock session.

### Enter
- product
- quantity
- reason or notes
- required photo evidence if prompted

### Save
Save the wastage record.

### Expected Result
The wastage entry should appear in the session records.

## Step 10: Record Stock Share

### When To Use
Use this when stock is shared with a partner.

### Open
The `Partners` page and switch to the `Stock Share` tab.

### Click
`Record Stock Share`

### Enter
- partner
- product
- quantity
- unit
- notes if needed

### Save
Save the stock share.

### Expected Result
The stock share should appear in the stock share list.

### If Payment Happens Later
Use `Mark paid` when the partner settles the share.

## Step 11: Record Closing Stock

### Open
The closing stock area inside the stock session.

### Enter
The stock still remaining at the end of the day.

### Save
Save the closing stock entries.

### Important Rule
Do not guess closing stock. Count it properly before saving.

## Step 12: Close The Stock Session

### Before Closing, Confirm
- important sales are recorded
- unpaid sales are handled correctly
- closing stock is recorded

### Click
The close session action.

### Confirm
Accept the confirmation prompt.

### Expected Result
The session should move from open to closed.

## Practical Daily Example

### Example Day
1. Open stock session
2. Record beef opening stock
3. Record bones and other incoming stock if delivered
4. Record mutura production
5. Sell raw meat, mutura, and soup
6. Record payment for any pending sales
7. Record wastage
8. Record closing stock
9. Close session

## Common Cashier Mistakes

### Selling Before Opening A Session
Fix:
- open the stock session first

### Choosing The Wrong Customer Type
Fix:
- if the sale is wholesale, select a wholesale customer before adding items
- if the sale is credit, select a credit customer

### Forgetting To Record Payment
Fix:
- open the sale details page and use `Record Payment`

### Trying To Close With Incomplete Work
Fix:
- record missing closing stock
- check unpaid sales
- confirm required entries are complete
