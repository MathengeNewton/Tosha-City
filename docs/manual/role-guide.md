# 2. Role Guide

## Purpose
This section explains what each main role is responsible for and what each role should avoid.

## Roles Covered
This manual focuses on the two active working roles:
- Admin
- Cashier

## Admin Role

### Main Responsibility
The admin sets up the system, controls branch structure, manages staff access, reviews reports, and supervises branch performance.

### Admin Can Do
- view the branch reporting dashboard
- create and manage branches
- create and manage users (staff)
- create and manage products
- create and manage recipes
- create suppliers, customers, and partners
- review reports
- view activity logs
- create sales
- **edit and delete sales** (corrections; follow your internal policy)
- record payments
- open and close stock sessions
- record stock entries
- **edit and delete stock entries** (corrections)
- record production runs

### Admin Should Use The System For
- first-time setup
- branch setup and cleanup
- user account management
- report review
- data correction when needed
- master data maintenance

### Admin Should Be Careful About
- creating branches before assigning staff
- creating products before creating recipes
- giving the correct branch to non-admin users
- understanding whether a product is raw stock, production item, or consumable
- setting the correct sale mode for prepared items

## Cashier Role

### Main Responsibility
The cashier runs day-to-day branch work.

### Cashier Can Do
- use the cashier dashboard
- open and close stock sessions
- record stock entries (**add new** entries; **editing or deleting entries that are already saved** is admin only)
- record production runs
- create sales (**editing or deleting an existing sale** is admin only)
- record payments
- create products
- create and update recipes
- create suppliers
- create customers
- create partners
- update partners

### Cashier Cannot Do
- open reports
- manage branches
- manage users (staff)
- **edit or delete existing sales** (ask an admin)
- **edit or delete existing stock entries** (ask an admin)
- open settings
- use other admin-only oversight areas

### Cashier Should Use The System For
- day opening
- stock capture
- production capture
- selling
- payment capture
- end-of-day closing

## Responsibility Split

### Admin Owns
- structure
- branch setup
- user setup
- master-data oversight
- reports and review

### Cashier Owns
- branch operations
- stock session work
- sales
- payment completion
- daily updates to records needed to keep operations moving

## Branch Responsibility Rule
Each cashier works within an assigned branch.

This means:
- the cashier should confirm the branch name before starting work
- the cashier should not assume they are working globally
- the admin should correct branch assignment before operations begin if the branch is wrong

## Practical Example

### Example: Admin Start-Up Day
1. Create branches
2. Create users
3. Assign cashier users to branches
4. Create products
5. Create recipes
6. Create suppliers, customers, and partners
7. Review branch reports once operations begin

### Example: Cashier Working Day
1. Log in
2. Confirm branch
3. Open stock session
4. Record opening stock
5. Record incoming stock if needed
6. Record production if prepared items are made
7. Create sales
8. Record payment for unpaid sales
9. Record closing stock
10. Close session

## Role Discipline
To keep the data clean:
- admins should avoid doing cashier work unless necessary
- cashiers should avoid changing setup data without approval
- every role should complete the current step before moving to the next one

## Quick Role Summary

### If You Are An Admin
You are responsible for setup, control, and reporting.

### If You Are A Cashier
You are responsible for running the branch correctly during the day.
