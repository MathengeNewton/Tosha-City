# 6. Reports Guide

## Purpose
This section helps admin users understand what each report shows and how to use it for branch review.

## Intended Audience
- Admin users

## Open The Reports Area
Open `Reports & Analytics`.

## Before Reading Any Report
Choose the filters first:
- `Start Date`
- `End Date`
- `Branch`

Use `Clear filters` when you want to return to the default view.

Use `Export Excel` when you want a spreadsheet copy of the current report.

## Sales Report

### What It Shows
- total sales count
- total paid revenue
- unpaid amount
- paid sales count
- sales by branch
- sales by product

### When To Use It
Use this report when you want to answer:
- which branch sold more
- how much revenue was collected
- how much is still unpaid
- which products sold most

### How To Read It
- high `Total Sales` means more transactions
- high `Total Revenue` means more paid income
- high `Unpaid Amount` needs follow-up
- use `Sales by Branch` to compare branch performance
- use `Sales by Product` to see the strongest items

## Stock Report

### What It Shows
- sales by price
- sales by quantity
- stock by branch
- stock by product

### Key Fields
- `Opening`
- `Incoming`
- `Closing`
- `Wastage`
- `Production Use`
- `Sales (KES)`
- `Sales (kg)`

### When To Use It
Use this report to review:
- stock movement
- product consumption
- stock position at the end of the period
- branch-level operational balance

### How To Read It
- high `Incoming` means more stock came in during the period
- high `Production Use` means more raw stock was consumed in recipes
- high `Wastage` should be investigated
- compare `Sales (KES)` and `Sales (kg)` to understand value and volume

## Wastage Report

### What It Shows
- total wastage
- total wastage entries
- products affected
- wastage by product

### When To Use It
Use this report to identify:
- where product loss is happening
- which product is wasted most often

### How To Read It
- repeated wastage on the same product usually means a handling or planning problem
- rising total wastage should be reviewed together with stock and production practices

## Stock Share Report

### What It Shows
- total quantity shared
- total entries
- partner count
- product count
- stock share by partner
- stock share by product
- all recorded stock share entries

### When To Use It
Use this report to:
- review how much stock was shared
- see which partners received stock
- follow up on unpaid partner shares

### How To Read It
- unpaid shares need active follow-up
- frequent stock sharing should be reviewed against branch stock performance

## Production Report

### What It Shows
- total runs
- expected output
- total output
- total sold
- total remaining
- productivity
- sell through
- wastage rate
- branch productivity table
- production by product
- production by recipe
- production entries

### When To Use It
Use this report to answer:
- which branch produces best
- whether recipes are delivering expected output
- whether prepared items are selling well
- whether production wastage is too high

### How To Read It

#### Productivity
Shows how actual output compares to expected output.

Higher is usually better.

#### Sell Through
Shows how much of produced output was sold.

Higher means the prepared product is moving well.

#### Wastage Rate
Shows how much production output was wasted.

Lower is better.

### Branch Productivity Table
Use this table when comparing branches side by side.

Look at:
- `Runs`
- `Expected`
- `Actual`
- `Sold`
- `Remaining`
- `Productivity`
- `Sell Through`
- `Wastage`

## Weekly Report

### What It Shows
- current week sales
- current week revenue
- last week sales
- last week revenue
- revenue change percent
- sales change percent

### When To Use It
Use this report for short management review and trend comparison.

### How To Read It
- positive change means growth
- negative change means performance has dropped

## Recommended Admin Review Routine

### Daily
Review:
- sales report
- stock report
- wastage report

### Weekly
Review:
- weekly report
- production report
- branch comparisons

### Monthly
Review:
- branch performance over a wider date range
- stock share behavior
- unpaid balances and recurring issues

## Common Report Questions

### Why Is Revenue Lower Than Expected?
Check:
- unpaid sales
- wrong customer type selection
- low sales volume
- low sell-through in production items

### Why Is Stock Reducing Too Fast?
Check:
- incoming stock totals
- production usage
- wastage
- partner stock share

### Why Is A Production Item Underperforming?
Check:
- recipe setup
- actual output versus expected output
- sell-through
- wastage rate

### Why Does One Branch Look Weak?
Check:
- whether the branch had an open session
- stock movement
- production runs
- sales count
- unpaid sales

## Report Discipline
- always set the date range first
- use branch filters when doing branch review
- read totals before reading detail lines
- compare branch rows before drawing conclusions
- export Excel only after you confirm the filters are correct
